# Free deployment options

## Option A — Vercel
1. Import the GitHub repository `yuvrajs166315-cmd/CHAMPS` into Vercel.
2. Framework: Vite.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Deploy.

## Option B — Netlify
1. Add the GitHub repository as a new site.
2. Build command: `npm run build`.
3. Publish directory: `dist`.
4. Deploy.

This version does not require Lovable credits or a paid backend to demonstrate the complete core UX. Data is persisted in the browser with localStorage.
